# MO-IT161 Project

## Setup

Install the project dependencies:

```bash
npm install
```

## Commands

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

Check formatting and lint rules:

```bash
npm run check
```

Automatically format files and fix lint issues:

```bash
npm run fix
```

Tailwind Setup

```bash
npm run css:build
```

## Simple Routing

This project uses client-side routing, so navigation works without a backend server.

- Home (public reports): `http://localhost:5173/`
- Dashboard: `http://localhost:5173/dashboard`
- Signup: `http://localhost:5173/signup`
- Signin: `http://localhost:5173/signin`
